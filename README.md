Glamorous Ramirez Kennel — Deployment Guide

FILES
- index.html (main site, mobile-responsive, shimmer on load)
- thank-you.html (confirmation page after payment)
- /assets (logos, favicon, crown-shimmer.css, social icons)
- /glamorous-ramirez-kennel (WordPress theme folder)

NETLIFY (fastest)
1) Go to https://app.netlify.com/drop
2) Drag and drop the entire ZIP (Glamorous-Ramirez-Kennel-Final.zip).
3) Netlify deploys instantly and gives you a live URL.
4) (Optional) Set a custom domain in Netlify settings.

GITHUB PAGES
1) Create a new repo, e.g. glamorous-ramirez-kennel
2) Upload index.html, thank-you.html, and the /assets folder to the repo root.
3) Repo Settings → Pages → Build and deployment → Deploy from branch → Select main branch, /(root).
4) Save. Your site will be live at https://<yourusername>.github.io/<reponame>/

WORDPRESS THEME
1) Zip the /glamorous-ramirez-kennel folder if needed and upload in WP Admin:
   Appearance → Themes → Add New → Upload Theme → Activate.
2) Create pages and assign templates (Parents, Puppies, Contact).
3) Set Homepage to a static page under Settings → Reading.
